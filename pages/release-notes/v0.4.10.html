RELEASE / 0.4.10

会議を離れず、録音と根拠を手元に。Stay in the meeting. Keep recording and evidence at hand.

kAIgi 0.4.10は、メニューバーと任意のノッチUIからの明示録音、設定可能な会議検出、プロジェクト固有名詞、確定発話だけのライブ対訳、時刻に紐づく画面根拠を追加し、PDF評価とSwiftUI描画境界も強化します。kAIgi 0.4.10 adds explicit recording from the menu bar and optional notch UI, configurable meeting detection, project terminology, confirmed-only live translation, and time-linked visual evidence, while strengthening PDF evaluation and SwiftUI rendering boundaries.

  • Version 0.4.10
  • Build 44
  • macOS 14+
  • Apple Silicon

常駐操作から、表示中の条件ですぐ録音Start immediately with the choices shown

nativeなメニューバーでスピーカー／マイクとAudioプロジェクトを確認し、赤い「録音を開始」からメインウインドウを開かずに録音できます。停止、画面根拠の保存、kAIgiを開く操作も同じ面にあります。Review system audio, microphone, and Audio-project choices in the native menu bar, then use the red Start Recording control without opening the main window. Stop, visual-evidence capture, and Open kAIgi remain on the same surface.

ノッチ付きMacでは同じ操作を任意のクリック式UIへ表示し、ノッチのない画面では上端カプセルへ戻ります。Reduce Motionを尊重し、nativeなメニューバーは常にfallbackとして残ります。On a notched Mac, the same controls can appear in an optional click-only surface; displays without a notch use a top capsule. Motion respects Reduce Motion, and the native menu-bar control always remains available.

会議検出と固有名詞を、録音の前から準備Prepare meeting detection and terminology before recording

Zoom、Google Meet、Microsoft Teamsの既知アプリと会議らしい有界なwindow情報を端末内で照合します。全体またはサービスごとに無効化でき、検出が録音、権限要求、スクリーンショットを開始することはありません。kAIgi locally checks known Zoom, Google Meet, and Microsoft Teams apps together with bounded meeting-like window information. Detection can be disabled globally or per service and never starts recording, permission requests, or screenshots.

任意のAudioプロジェクトへ会社名、製品名、人名など最大40語を登録し、その録音のApple Speech文脈へ優先的に渡せます。過去資料から議題候補を作る会議前メモも明示ボタンで準備します。An optional Audio project can contribute up to 40 company, product, and person names to that recording's Apple Speech context. A separate explicit action prepares a pre-meeting brief from prior project evidence.

原文を残すライブ対訳と、時刻に紐づく画面根拠Live translation that preserves source speech, plus time-linked visual evidence

ライブ対訳は既定でOFFです。有効時も確定済み発話だけを端末内処理し、原文の直下へ表示します。数字や保護された固有名詞を失った訳は表示せず、正本の文字起こしを上書きしません。Live translation is off by default. When enabled, it processes only confirmed utterances on device and appears beneath the source. Results that lose numbers or protected terms are withheld, and the canonical transcript is never overwritten.

録音中の明示クリックで、直前の前面ウインドウを1回だけ撮影し、PNG、有界なwindow情報、録音内時刻、端末内OCRをVisualデータへ保存できます。自動撮影やスライド切替監視は行いません。An explicit click during recording captures the previously active window once and stores the PNG, bounded window information, recording-relative time, and on-device OCR as Visual data. There is no automatic capture or slide-change monitoring.

実論文をコピーせず、PDF品質を評価Evaluate real papers without copying their PDFs

同意済みの二段組、表、図、脚注、scan PDFを、仮名case IDとhashだけのfrozen manifestで評価できるlocal laneを追加しました。元PDF、title、path、本文、OCR textをrepositoryやreportへコピーしません。A local lane can evaluate consented two-column, table, figure, footnote, and scanned PDFs through a frozen manifest containing pseudonymous case IDs and hashes. Source PDFs, titles, paths, prose, and OCR text are not copied into the repository or reports.

製品のOCRは従来どおり明示操作です。前後previewと対象pageを確認し、不足pageだけをApple Visionで補修します。Harness v3の追加敵対的評価は、実失敗を先にfreezeした別splitを用意するまで延期します。Product OCR remains explicit: review before and after previews, select pages, and repair only missing text with Apple Vision. Additional adversarial Harness v3 evaluation remains deferred until real failures are frozen into a separate split first.

必要な面だけLiquid Glass、必要な値だけ再描画Liquid Glass only where it belongs, rendering only when values change

常駐UIは録音、会議検出、画面根拠の小さな表示snapshotだけを監視します。表示値が変わらない診断pollやlibrary更新を重複排除し、同値の状態保存と重複animationも削減しました。Resident UI observes small recording, meeting, and evidence presentation snapshots. Equal diagnostic polls and library updates are deduplicated, while no-op state writes and duplicate implicit animations are removed.

macOS 26ではheader、検索、status、常駐操作などの浮遊chromeへnative Liquid Glassを限定適用します。本文cardやwindow全体へ反復せず、macOS 14／15ではmaterialとbordered controlへ安全に戻ります。On macOS 26, native Liquid Glass is limited to floating chrome such as headers, search, status, and resident controls. It is not repeated across content cards or the whole window, and macOS 14 and 15 retain material and bordered fallbacks.
