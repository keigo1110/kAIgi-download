kAIgi 0.5.5

Version 0.5.5 / Build 57

読むための処理を、軽く。Less repeated work behind your reading.

論文の構造・対訳、長い会議、検索の処理準備を効率化しました。More efficient preparation for paper structure, parallel translation, long transcripts and retrieval.

論文の構造・対訳Paper structure and parallel translation

章立て・段落要旨・対訳の表示に必要な計算を共有し、同じ本文を繰り返し処理する無駄を減らしました。構造化の準備は、その回に実行できる範囲へ絞ります。PDFの文字修復とページ位置の照合も効率化しました。Outline, gist and translation views reuse preparation instead of repeatedly processing the same text. Structure planning stops at the current run's work budget. PDF font-repair lookup and page geometry queries also do less repeated work.

文書や翻訳言語を変更した場合は現在の原文との対応を確認します。原文・注釈・保存形式・翻訳モデルは変更しません。Changing a document or translation language still checks correspondence with the current source. Originals, annotations, stored formats and translation models are unchanged.

会議・検索・辞書Meetings, retrieval and lookup

コピー用の文字起こし本文はコピー操作時に組み立てます。文章結合、話者名の照合、Askの直近発話、Recallの代表資料選択と旧マップの準備も効率化しました。選択順と根拠は維持します。Transcript copy text is assembled when you copy, not while showing the button. Grouping, speaker lookup, recent Ask context, Recall representative selection and legacy map preparation also avoid repeated work. Selection order and evidence are preserved.

⌘C二連続の対象外アプリ設定をキー入力ごとに解析し直さなくなりました。翻訳・辞書の操作や履歴を保存しない方針は変わりません。Double-Copy no longer reparses excluded-app settings on every key event. Translation and dictionary behavior, including no lookup history, is unchanged.

既知の制限Known limitations

今回は重複計算と処理準備の改善です。モデル精度の向上やすべての操作の待ち時間短縮を保証しません。翻訳・要旨は専門語・条件・留保を誤ることがあります。原文も確認してください。複雑な雑誌レイアウトや図・表内部の完全復元は対象外です。These changes improve preparation, not model accuracy or every interaction's latency. Translations and gists can misread terminology, conditions and qualifications; check the original. Full reconstruction of complex magazine layouts and diagram/table internals is outside this release's scope.

Sparkle自動更新の実操作は未検証で、今後の公開の必須確認には含めません。署名・公証・更新フィードと配布ファイルの検証は維持します。Real Sparkle updates are unverified and are no longer a release prerequisite. Signing, notarization, appcast and downloaded-artifact verification remain required.
