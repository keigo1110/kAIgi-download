kAIgi 0.7.2

Version 0.7.2 / Build 62

PDFが届く前に論文を登録Save a citation before you have the PDF

  • CLIで題名・著者・年・DOIなどを登録し、後から同じ文献にPDFを追加できます。文書ID、所属プロジェクト、メモは引き継がれます。Register a title, authors, year and DOI from the CLI, then attach the PDF to the same record. Its document ID, projects and notes are preserved.
  • 文献リストを一括登録すると、各項目の結果がJSONで返ります。同じリストを再投入しても、照合できた文献は既存の記録を使います。Import a reading list in one operation and inspect the result for each entry in JSON. Matched records are reused when you retry.

プロジェクトと論文間の関係Projects and relationships between papers

  • プロジェクトにブックマークした論文は「お気に入り」にもまとまります。CLIの文書一覧には、各プロジェクトのIDと現在の表示名が出ます。Papers bookmarked in a project also appear in Favorites. The CLI document list shows each project’s ID and current name.
  • 論文同士の関係に根拠のページと段落を付け、読書画面で確認できます。CLIからも関係と根拠を読み出せます。Link papers to a supporting page and paragraph, review the link in the reader, and retrieve the relationship and passage from the CLI.

索引から原著を探すFind original papers from a reading list

  • CLIの検索では同じ論文の版をまとめられます。索引で説明と正式題名を照合できると、原著を開くコマンドが出ます。Askでも、新しい検索で索引の見出しから論文を特定できたときは、候補の論文と索引を一緒に開けます。Group editions in CLI search. When a matching index entry contains an identifiable full title, the CLI returns a command to open the paper. In a new Ask search, a matched index heading can surface both the paper and its index.

AI連携の公開範囲Control what the CLI can access

  • 「設定 → AI連携」で、CLIに公開しないファイルとフォルダをそれぞれ選べます。フォルダを選ぶと、中の項目も除外します。In Settings → AI Integration, choose files or folders to exclude from the CLI. Excluding a folder also excludes its contents.
