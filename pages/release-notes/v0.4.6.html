RELEASE / 0.4.6

構造から読み、自分の考えを残す。 Read the structure. Keep your own thinking.

kAIgi 0.4.6は、論文の短い構造を読書の入口にし、文書全体への自由なノートと、原文へ戻れる付箋を一つの作業面へまとめます。自分の考察と引用可能な根拠は、アプリでもCLIでも明確に分けます。 kAIgi 0.4.6 starts paper reading from a concise structure and brings freeform document notes together with stickies that return to the source. Your thinking stays explicitly separate from citable evidence in both the app and CLI.

  • Build 40
  • macOS 14+
  • Apple silicon + Intel

Structure & Notes

論文を理解する作業面を、一つに One workspace for understanding a paper

  • 構造を既定の入口にStructure becomes the default entry point Text右ペインを「構造・ノート・対訳・質問」の順にし、まず論文の全体像と読み筋を掴めるようにしました。狭い幅では切り替えを一行メニューへ畳みます。 The Text companion opens in the order Structure, Notes, Translation, and Questions, so the paper's shape and reading path come first. At narrow widths, the switcher collapses into a single-line menu.
  • 自由なノートと根拠付き付箋Freeform notes and grounded stickies 場所に依存しない感想や論点は大きな文書ノートへ、段落やPDF注釈に結び付く記述はその下の付箋へまとめます。付箋から元のPDF箇所へ戻れます。 Keep location-independent reflections in a larger document note, and source-bound paragraph or PDF comments as stickies below it. Each sticky can return to its original PDF location.
  • 入力を止めず、消去は確認するType smoothly and confirm destructive clearing ノート入力はPDFを含む画面全体を毎打鍵で描き直しません。文書切替や終了前に保存し、「消去」は確認してから実行します。 Note typing no longer redraws the full PDF workspace on every keystroke. Drafts save before document changes or quit, and clearing requires confirmation.

Reliable summaries

翻訳ではなく、短い要点と読み筋へ Concise points and a reading path, not a translation

  • 言語と圧縮を検査Validate language and compression 各段落の要点を一文に限定し、選択した言語、長さ、原文に対する圧縮率を確認します。本文をほぼそのまま翻訳した出力や、別言語へ逸脱した出力は保存しません。 Each passage point is limited to one sentence and checked for the selected language, length, and compression against the source. Near-verbatim translations and wrong-language output are not saved.
  • 欠けた読み筋だけを補うRepair a missing reading path without discarding valid work 読み筋の生成だけが失敗した場合は一度再試行し、それでも欠ける時は有効な要点を再利用して「残りを補う」ことができます。 If only the reading path fails, kAIgi retries once. If it is still missing, “Complete the rest” reuses valid points and repairs only the unfinished result.
  • 注意事項は必要な時だけExtraction notices stay on demand 段組み判定やPDF注釈の上限は常設バナーにせず、右ペインの一つの警告アイコンへ集約しました。構造やノートの表示領域を圧迫しません。 Column-detection uncertainty and PDF annotation limits now share one on-demand warning in the companion header instead of permanent banners that consume reading space.

Identity & space

正しい版へ戻り、作業領域を広く保つ Return to the right revision and preserve working space

  • 別論文を同じ版として提案しないDo not suggest a different paper as another revision DOIとarXiv IDは第一ページ上部の本人確認領域だけから読み、参考文献にあるIDを使いません。固有タイトルが十分に一致しない候補も除外します。 DOI and arXiv IDs are read only from the first-page identity region, never from references. Candidates with distinct titles that do not sufficiently agree are also rejected.
  • 質問欄を一行に保つKeep question composers on one line AskとText／Audioの質問欄は、幅に合わせて端末内処理の説明と送信操作を短縮し、入力欄と会話領域を優先します。 Ask and Text/Audio question composers progressively shorten privacy and send controls as space narrows, preserving the input and conversation area.
  • プロジェクトは5件ずつExpand projects five items at a time Audio、Text、Visualのプロジェクトは最初に最大5件を表示し、「さらに開く」で5件ずつ追加します。閉じると次回は5件へ戻ります。 Audio, Text, and Visual projects initially show up to five items and add five per expansion. Closing a project resets it to five for the next open.

Agent context

自分のノートを、原文と混ぜずに渡す Pass your notes without blending them into the source

  • document_note / document_note_scope documents inspect、documents context、documents research-context は文書ノートを返します。source_evidence: false が、自分の考察を引用可能な原文から機械的にも区別します。 documents inspect, documents context, and documents research-context return document notes. source_evidence: false keeps your thinking machine-readably distinct from citable source text.
  • バックアップの競合を黙って捨てないDo not silently discard backup conflicts 同じノートを別の場所で編集した版は既読扱いにせず、競合として取込を止めます。確認後に内容が変わった時も、古い確認結果では続行しません。 A note edited independently is not discarded as already imported; it stops the import as a conflict. If content changes after review, the stale confirmation cannot continue.

知っておいてほしいこと What to know

Askと「質問」は引き続き実験的です。検索と回答はこのMac内で処理し、会話は保存しませんが、生成結果が学術的に正しいことを自動証明するものではありません。重要な内容は出典を開いて確認してください。 Ask and Questions remain experimental. Search and answering run on this Mac and conversations are not saved, but generated output is not automatic proof of scholarly correctness. Open the cited source for important claims.

文書ノートは自分の考察であり、著者の記述ではありません。CodexやClaude Codeをクラウドモデルで使う場合、選択したCLI出力はモデル提供元へ送られることがあります。0.4.6でノートを保存した文書を0.4.5で開くと、互換性保護のためノートとコメントは読み取りません。0.4.6へ戻せば再び利用できます。 A document note is your own thinking, not the author's text. When Codex or Claude Code uses a cloud model, selected CLI output may be sent to that model provider. If a document with a 0.4.6 note is opened in 0.4.5, notes and comments are withheld for compatibility safety and become available again when reopened in 0.4.6.
