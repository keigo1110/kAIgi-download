RELEASE / 0.4.12

より軽く、壊れた根拠を見逃さない。Leaner in use, stricter with broken evidence.

kAIgi 0.4.12は、録音中の重複計算と不要な再描画を減らし、ノッチの操作経路、スライド根拠の完全性、ローカル検証の失敗検出を強化する安定化releaseです。kAIgi 0.4.12 is a reliability release that removes duplicate recording work and unrelated redraws, then strengthens notch routing, slide-evidence integrity, and local failure detection.

  • Version 0.4.12
  • Build 46
  • macOS 14+
  • Apple Silicon

録音の1チャンクを1度だけ計算Measure each recording chunk once

録音レベルは文字起こし用に正規化した同じ音声から再利用し、生のbuffer全体をもう1度走査する処理を除きました。交互配列のステレオは全チャンネルから正しく計測します。The input meter now reuses the normalized audio already measured for transcription instead of scanning every raw buffer again. Interleaved stereo and other multichannel input is measured across every channel.

高頻度のレベル更新は専用の軽量modelだけを更新し、巨大なRecordingViewModelと無関係な画面の再描画を発生させません。High-frequency level changes now update a small dedicated model rather than invalidating the large RecordingViewModel and unrelated UI.

ノッチを安定した常駐コントロールへA more reliable resident notch

メインウインドウを開く経路をappの寿命に合わせて保持し、ノッチ表示中にメニューバー項目を隠してもOpen操作を失いません。連打したOpen要求は最大1件へまとめます。Main-window routing is retained for the app lifetime, so Open remains available while the duplicate menu-bar item is hidden. Repeated Open requests coalesce to one pending action.

閉じたノッチはVoiceOverでボタンとして読み上げ、デフォルト操作で開けます。Reduce Motionの変更も再起動なしで反映し、動きを減らしても状態を文字で判別できます。The collapsed notch is exposed as a VoiceOver button with a default action. Reduce Motion changes apply without relaunching, while stable labels keep state perceivable without animation.

根拠の破損は、「空」にしないBroken evidence never becomes an empty success

スライド根拠の検索indexは再構築できますが、正本のasset manifestが破損している場合は「根拠0件」として続行しません。読めない件数を明示し、不完全なindexを正常な結果として保存しないようにしました。The slide-evidence lookup can be rebuilt, but a corrupted authoritative asset manifest no longer becomes a successful result with zero evidence. kAIgi reports the withheld count and refuses to save an incomplete index as healthy.

Vision用の画像フォールバックは最大寸法を制限します。極端なcropにより巨大な全面rasterが必要になる時は、メモリを使い尽くす前に安全に停止します。The Vision raster fallback has a maximum dimension. An extreme crop that would require a huge full-page raster stops safely before exhausting memory.

出力を減らしても、失敗は減らさないLess output, not less failure evidence

大量テストの成功時は正確な件数と時間だけを短く表示し、完全な出力は容量上限と権限を持つlocal logへ保存します。失敗時は最初と最後の重要部分を表示し、詳細logへすぐ移れます。Large successful suites print only exact counts and duration while retaining complete, size-bounded owner-only logs. Failures show bounded first and last diagnostic context and the full local log path.

フィルタ誤りのテスト0件、全件skip、log上限超過、中断後の残留プロセス、検証中のsource変更は成功にしません。dirtyなtrial buildもcleanなrelease evidenceと区別します。Zero matched tests, all-skipped suites, log overflow, lingering descendants, and source changes during verification all fail closed. A dirty trial build also remains distinct from clean release evidence.

プライバシー境界は変更なしNo privacy-boundary change

0.4.12で新しい外部送信、保存形式、データ保持方針の変更はありません。Apple Silicon MacとmacOS 14以降が対象です。Version 0.4.12 adds no external transmission, storage-format, or retention-policy change. It supports Apple Silicon Macs running macOS 14 or later.
