RELEASE / 0.4.8

答えの経路を見せ、検索とPDFを磨く。 Trace the answer. Control the search. Read the PDF.

kAIgi 0.4.8は、Gemmaの回答経路と検証結果を控えめに表示し、Deep Researchの検索条件を送信前に編集できるようにしました。PDFの構造と要約も、引用・数値・言語を検証するGemmaハーネスへ統合しています。 kAIgi 0.4.8 quietly exposes the route and validation behind Gemma answers, lets you edit Deep Research scope before sending, and brings PDF structure and summaries into a citation-, number-, and language-validated Gemma harness.

回答本文を邪魔せず、経路と根拠を示す Show route and evidence without crowding the answer

AskとText／Audioの「質問」は、回答の下にGemma QAT、Apple fallback、決定的回答、根拠候補へのfallbackのどれを使ったか表示します。詳細には引用件数、要確認の根拠、競合値、再検証の実施、完成回答を出さなかった理由をまとめ、通常はpopoverへ畳みます。 Ask and source Questions now label whether they used Gemma QAT, Apple fallback, a deterministic answer, or an evidence-candidate fallback. Citation counts, evidence requiring review, conflicting values, verification passes, and refusal reasons stay folded into a popover by default.

表示するのはモデルの思考過程ではなく、アプリが確認できる経路、検証結果、引用元です。根拠にない数値、否定、増減方向、因果関係、未知の引用は回答境界で拒否します。 This is not model chain-of-thought. It exposes only the route, validation facts, and cited source material that the app can verify. Unsupported numbers, negation, direction, causality, and unknown citations are rejected at the answer boundary.

送信する検索条件を、先に確認する Review the exact search scope before sending

Deep Researchの開始前に、検索語、期間、最大4件のドメインを編集できます。簡易マスキングやドメイン正規化で値が変わる場合は、実際に送る条件も画面へ表示します。 Before Deep Research starts, you can edit the query, time range, and up to four domains. If lightweight masking or domain normalization changes a value, kAIgi also shows the exact scope it will send.

結果にはDuckDuckGo／Wikipediaの状態、重複除去件数、検索時刻、memory cache、公開日を添えます。指定外ドメインのURLはPython helperとSwift公開境界の両方で拒否し、同一条件のcacheは最大10分だけメモリ上に保持します。結果ページ本文は自動取得しません。 Results expose DuckDuckGo and Wikipedia status, deduplication, search time, memory-cache use, and publication dates when available. URLs outside an allowed domain are rejected by both the Python helper and Swift publication boundary. Matching queries remain in memory for at most ten minutes, and result pages are never fetched automatically.

PDFの構造と要約を、検証してから保存する Validate PDF structure and summaries before saving

「構造を生成」は検証済みGemma 4 E4B QATを優先します。段落ID、見出し、根拠ID、exact JSON schema、引用、数値、要求言語、要約密度をアプリが検証し、通らない項目だけ対応環境のAppleオンデバイスモデルへ戻します。 Generate Structure now prefers the verified Gemma 4 E4B QAT model. kAIgi validates paragraph and evidence IDs, headings, the exact JSON schema, citations, numbers, requested language, and summary density, then falls back to Apple's on-device model only for rejected work on supported systems.

長い資料は上限付きbatchで処理し、完成分を逐次保存します。残りの段落・section・読み筋を表示して安全に再開できるため、1回の操作が無制限な生成requestへ膨らみません。text layerとOCRには同じ狭いUnicode正規化と検証を適用します。 Long documents run in bounded batches and publish completed work incrementally. Remaining paragraphs, sections, and overview work stay visible and resumable, so one click cannot expand into unbounded generation. Text-layer and OCR input share the same narrow Unicode normalization and validation path.

会議を見つけても、録音は勝手に始めない Detect a meeting without ever auto-recording it

kAIgiが前面にある間、Zoom、Google Meet、Teams等の既知アプリと会議らしいwindow titleを端末内で確認し、録音可能な場合だけ小さな開始操作を表示します。汎用titleだけでは会議とみなさず、誤検出を避けます。 While kAIgi is in front, it locally checks known apps such as Zoom, Google Meet, and Teams together with meeting-like window titles, then offers a small recording action only when recording is available. Generic titles alone do not count as a meeting.

提案をクリックしても従来の録音確認が開くだけで、録音は自動開始しません。window titleは保存、log、外部送信しません。検出できない場合も通常の録音操作は変わりません。 Clicking the suggestion opens the existing confirmation; recording never starts automatically. Window titles are not stored, logged, or transmitted. The ordinary recording control remains available when detection does not match.

Local AIの配布量を、用途を変えずに減らす Reduce Local AI downloads without changing their purpose

Gemma QATから回答に使わないvision tensorを除き、新規ダウンロードを約956MB削減しました。固定revision、全SHA-256、tensor一覧、ファイル世代、process間lockの検証は維持し、既存モデルをbackgroundで削除・書き換えません。 The Gemma QAT download omits a vision tensor unused by grounded answers, reducing new downloads by about 956 MB. Pinned revision, complete SHA-256 checks, tensor inventory, file generations, and cross-process locks remain enforced, and existing models are never rewritten or deleted in the background.

AI Researchは新規install時OFFのままです。Gemmaの回答、PDF要約、Ask、会議検出は端末内で行います。Web検索を有効にした場合だけ、画面で確認した短い検索条件をDuckDuckGoとWikipediaへ送信します。 AI Research remains off on new installations. Gemma answers, PDF summaries, Ask, and meeting detection stay on device. Only when web research is enabled does kAIgi send the short search scope shown in the UI to DuckDuckGo and Wikipedia.
