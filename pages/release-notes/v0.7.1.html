kAIgi 0.7.1

Version 0.7.1 / Build 61

CLIで論文を取り込んで読むImport and read papers from the CLI

  • kaigi documents importで、手元のPDF、公開PDFのHTTPS URL、arXivの抄録ページから論文を取り込めます。出版社でログインが必要な場合は、kAIgiの内蔵ブラウザで取り込んだ後にCLIで読めます。Use kaigi documents import with a local file, a public HTTPS PDF URL, or an arXiv abstract page. For publisher sign-in, import through the built-in browser and continue reading from the CLI.
  • ページを指定して関連研究節の本文を読み、複数の論文を検索し、保存したページ画像を取り出せます。取り込み時に文字が欠けているページは自動でOCRします。Read text by page, search across saved papers, and export page images. Import automatically runs OCR on pages that need it.

ブックマークと読書記録Bookmarks and reading history

  • 同じ論文を複数のプロジェクトにブックマークできます。Bookmark the same paper in multiple projects.
  • PDFのハッシュが異なる場合も、DOI・本文・全ページの画像などが一致すれば、既存の読書記録を開きます。Reuse the existing reading record for PDFs with different file hashes when the DOI, saved text, page images, and other reading evidence match.

修正Fixes

  • Recall Guideで、同じ日付の資料に異なる値が書かれているとき、安定してその違いを検出できるようにしました。Recall Guide now consistently detects conflicting values in sources with the same date.
