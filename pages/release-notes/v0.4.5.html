RELEASE / 0.4.5

探して、根拠から尋ねる。 Find it, then ask from the evidence.

kAIgi 0.4.5は、保存済みの会議録と論文をAskで探し、そのまま根拠付きで内容を尋ねられます。CodexやClaude Codeへは、会議と論文の正確な根拠を一つの有界なコンテキストとして渡せます。 kAIgi 0.4.5 finds saved meetings and papers through Ask, then answers content questions with traceable evidence. Codex and Claude Code can receive exact meeting and paper evidence in one bounded context.

  • Version 0.4.5
  • Build 39
  • macOS 14+
  • Apple silicon + Intel

Grounded Ask

候補探しから、内容の質問まで From finding candidates to questioning their content

  • Recall・Ask・Zoomを役割で分けるRecall, Ask, and Zoom have distinct roles Recallは検索結果を直接読む一覧、Askは会議録と論文を対話的に探して尋ねる面、Zoomは資料全体を眺める意味の地図です。 Recall is the direct result list, Ask finds and questions meetings and papers conversationally, and Zoom is the semantic overview of the library.
  • 1資料だけに聞ける「質問」Questions stay within one selected source Textでは論文、Audioでは会議録を一つだけ選び、要約や実験参加者数などを尋ねられます。回答の出典から元のPDF段落または発話を開けます。 Select one paper in Text or one meeting in Audio and ask for a summary, participant count, or another detail. Citations open the original PDF passage or utterance.
  • 短い回答と検証済みの出典Concise answers with validated citations 質問の言語に合わせて通常1〜3文で返します。未知の出典、根拠不足、生成失敗は完成回答として採用せず、確認できる根拠候補へ戻します。 Answers normally use one to three sentences in the question's language. Unknown citations, insufficient evidence, or generation failure are not accepted as finished answers; kAIgi falls back to inspectable evidence candidates.

Agent context

会議と論文を、一つの問いでCodexへ Bring meetings and papers into Codex under one question

  • kaigi context "テーマ" 保存済み会議録と抽出済み論文を一度に検索し、正確な文字起こし区間とPDF段落をまとめます。 Searches saved meetings and extracted papers together and returns exact transcript intervals and PDF passages.
  • 原文へ戻れる識別情報Identity that returns to the original source 元データのSHA-256、発話時刻、ページ、段落ID、本文ハッシュ、一致語、次に深く読むためのコマンドを保持します。 Source SHA-256, utterance timing, page, block ID, passage hash, matched terms, and next-step reading commands stay attached.
  • 未確認を「該当なし」にしないDo not turn “unchecked” into “not found” completeness.recordings と completeness.documents が、走査件数、完了、省略、読めなかった候補を種類別に返します。CLIは回答や論文レビューそのものを生成しません。 completeness.recordings and completeness.documents report scan counts, completion, omissions, and unreadable candidates per source kind. The CLI does not generate an answer or literature review.

Work surfaces

読む・聞く・眺める場所を広く More room to read, listen, and explore

  • ZoomとPDFを端まで使うUse the full Zoom and PDF surfaces 意味の地図とPDF本体から不要な外枠を外し、主作業面を広げました。PDF名にもリーダー相当の横幅を確保します。 Unnecessary outer framing is removed from the semantic map and PDF body, while document titles receive the reader's usable width.
  • 補助情報は必要な時だけSecondary information appears on demand Audioの認識情報は文字起こしツールバーの情報アイコンへ移し、Askと質問のプライバシー表示も入力操作と同じ1行へまとめました。 Audio recognition details move behind an info button in the transcript toolbar, and Ask privacy status now shares the same row as composing controls.

Askと「質問」は実験的です Ask and Questions are experimental

検索と回答はこのMac内で処理し、会話は保存しません。Appleのオンデバイス回答にはmacOS 26以降、Apple Intelligence対応Mac、利用可能なモデルと言語が必要です。利用できない場合は、準備済みLocal LLMへ切り替え、どちらも使えなければ根拠候補だけを表示します。 Search and answering run on this Mac and conversations are not saved. Apple's on-device answers require macOS 26 or later, an Apple Intelligence-capable Mac, and an available model and language. kAIgi falls back to a prepared Local LLM, then to evidence candidates when neither model is available.

回答の引用は検証しますが、学術的な正しさや根拠が主張を十分に支えることまで自動証明するものではありません。重要な内容は出典を開いて原文で確認してください。CodexやClaude Codeをクラウドモデルで使う場合、CLI出力は選択したモデル提供元へ送られることがあります。 kAIgi validates citation identity, but it cannot prove scholarly correctness or that the cited evidence fully supports a claim. Open the source and verify important content. When Codex or Claude Code uses a cloud model, CLI output may be sent to the selected model provider.
