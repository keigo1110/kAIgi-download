RELEASE / 0.5.1

つないだ資料を、待たずに開く。Open connected sources without waiting.

kAIgi 0.5.1は、接続フォルダをすぐ操作できるLibrary、PDF・Markdown・HTML・テキストに共通するDocument Workbench、軽量で復旧可能な検索基盤を導入するメジャーアップデートです。kAIgi 0.5.1 is a major update with an immediately usable connected Library, one Document Workbench for PDF, Markdown, HTML, and text, and a lightweight recoverable search foundation.

  • Version 0.5.1
  • Build 49
  • macOS 15+
  • Apple Silicon

一覧更新を待たない接続LibraryA connected Library that does not wait for indexing

フォルダを接続した直後から階層を展開し、ファイルを選んで開けます。ファイル名と相対パスの軽量な一覧はバックグラウンドで更新され、大きなフォルダでもファイル数だけを理由に途中で打ち切りません。You can expand the hierarchy and open a file as soon as a folder is connected. A lightweight filename and relative-path catalog refreshes in the background without stopping solely because a folder contains many files.

容量不足、権限変更、途中終了では、確認済みの前回一覧を保持したまま理由と再試行を表示します。iCloudなどの未ダウンロードファイルを検索のために自動取得しません。On capacity pressure, authority changes, or interruption, kAIgi keeps the last verified catalog and presents the reason and a retry. It does not download cloud placeholders merely for search.

一つのDocument WorkbenchOne Document Workbench

PDF、Markdown、HTML、一般的なテキスト文書を、一貫したヘッダー、サイドバー、文書内検索から扱えます。Markdownは整形済みプレビューと編集可能なソース、HTMLは対話的なプレビューとソース、PDFは専用ビューアで開きます。HTML内のJavaScript、画像、フォームなどは通常のブラウザと同様に通信できるため、信頼できるHTMLだけを開いてください。PDF, Markdown, HTML, and ordinary text documents now share a consistent header, sidebar, and find-in-document location. Markdown offers rendered preview and editable source, HTML offers interactive preview and source, and PDF keeps its specialized viewer. Because JavaScript, images, forms, and other HTML content can communicate as they do in a browser, open only HTML you trust.

未保存の変更、Finder側の更新、接続権限の喪失を区別し、現在のファイルだと確認できた場合だけ保存・移動・削除を進めます。Unsaved edits, Finder-side changes, and lost connection authority remain distinct. Save, move, rename, and deletion proceed only after revalidating the current file.

探しやすいツリーとファイル操作A clearer tree and familiar file actions

Libraryを「接続フォルダ」「プロジェクト」「最近開いたファイル」「検索」のアイコンへ整理し、フォルダ階層をコンパクトなツリーで表示します。検索結果はファイルごとにまとめ、一致箇所へ移動できます。The Library is organized into Connected Folders, Projects, Recent Files, and Search icons, with a compact folder tree. Search results are grouped by file and can navigate to a matching location.

ファイル名・パスに加え、Markdown、保存済みHTMLソース、読める一般テキスト、テキストを抽出できる接続PDFの本文を探せます。候補は現在の原文で再確認し、結果が多い場合は「さらに検索」で次の有限バッチへ進めます。HTMLはタグを含む保存済みソースが対象で、ブラウザの表示結果、画像だけのPDFやOCR、Office形式は本文検索の対象外です。Search names and paths plus Markdown, saved HTML source, readable plain text, and connected PDFs with extractable text. Each candidate is rechecked against the current source; More Search advances through bounded batches. HTML search includes saved markup, not the browser's rendered output. Image-only PDFs, OCR, and Office formats are outside body-search support.

右クリックから、ブラウザで開く、Finderで表示、アプリケーションを選んで開く、共有、切り取り、コピー、貼り付け、パス／相対パスのコピー、名前変更、削除を利用できます。同名ファイルは黙って上書きしません。The context menu offers Open in Browser, Show in Finder, Open With, Share, Cut, Copy, Paste, Copy Path, Copy Relative Path, Rename, and Delete. Existing files are never overwritten silently.

軽量で、根拠を推測しない検索Lightweight search without guessed evidence

接続一覧には本文を複製せず、名前、相対パス、形式、現在性の確認に必要な情報だけを保存します。macOSのSpotlightは候補探索にだけ使い、抜粋や位置を根拠として信用しません。本文結果は現在の原文を再確認してから表示・移動します。The connected catalog stores no source body—only the name, relative path, format, and bounded observations needed for freshness. Spotlight supplies candidates, never evidence: kAIgi rereads and verifies the current source before publishing or opening a body match.

Spotlightの0件や候補の確認終了は「一致なし」の証明ではありません。正式版は同じ署名済み実装候補に結び付いた品質証拠と、このMac／フォルダでの利用可否確認を通過した時だけ新方式を有効にし、新しい旧形式索引を作りません。一度移行した後は旧形式への書き込みと本文fallbackを止め、同じ0.5.1系の移行・復旧用にだけ読み取り専用で保持します。0.4.13へ戻した場合、従来のmanaged Text／PDFは開けますが、Connected Libraryの状態は保持されたまま旧版からは見えません。Zero Spotlight candidates or exhausting a candidate batch do not prove absence. The release enables the new path only after verifying evidence bound to the exact signed candidate and a capability probe for this Mac and root, and it creates no new legacy index. After cutover, legacy writes and body fallback stay disabled; the frozen index is retained only for same-family 0.5.1 migration and recovery. Returning to 0.4.13 preserves access to the managed Text/PDF library, while Connected Library state is retained but unreadable by that older version.

外部で整えたPDF構造と、失敗時の操作性External PDF structure and responsive failure handling

CLIのdocuments structure export／validate／applyで、読み筋、段落の要点、見出し階層を取り込めます。検証は保存を変えず、適用は元資料・抽出内容・既存構造の版を照合して構造データだけを原子的に更新します。CLI自身はモデルも通信も使わず、内容品質を保証するものではありません。アプリへ戻ると新しい構造を再読込します。The CLI documents structure export, validate, and apply workflow imports an overview, paragraph gists, and heading levels. Validation is read-only; apply checks the source, extraction, and base structure revisions before atomically replacing only structure data. The CLI runs no model or network request and does not guarantee editorial quality. Returning to the app reloads the new structure.

接続PDFを開けない状態で、同じ失敗状態の通知と画面再描画が繰り返される循環を防ぎました。読取失敗そのものとは分けて扱い、理由と明示的な再試行を表示します。A failed connected-PDF open no longer repeatedly publishes the same failure state and triggers a redraw cycle. This fix is separate from the initial read failure, whose reason and explicit retry remain visible.

接続だけでは意味検索を有効にしないConnecting a folder does not enable semantic retrieval

軽量な一覧に本文、検索語、Spotlightの抜粋、埋め込みベクトル、AI生成文は保存しません。フォルダを接続しただけで意味検索用モデルを読み込んだり、外部サービスへ文書を送ったりしません。意味検索は、将来の明示的な同意と独立した保存境界を必要とします。The catalog stores no source body, query, Spotlight snippet, embedding vector, or generated text. Connecting a folder does not load a semantic model or send a document to an external service. Semantic retrieval remains a future, separately consented storage boundary.

Apple Silicon MacとmacOS 15以降が対象です。kAIgi 0.5.1 supports Apple Silicon Macs running macOS 15 or later.
