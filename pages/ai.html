AI連携AI integration

会議の続きを
いつものAIに頼む。Bring your meetings to your AI agent.

CodexやClaude Codeに「kAIgiを使って」と頼めます。作りたいものを伝えると、会議の発言や論文の一節を探して下書きに使います。Tell Codex or Claude Code what you want to write and ask it to use kAIgi. Your agent can draw on meeting transcripts and papers as it drafts.

AI連携を設定するConnect your agent

出典を確かめて、続きを頼む。Check the sources, then follow up.

発言の時刻や論文のページを添えてもらえば、下書きを原文と照らし合わせられます。この例なら、計画を確かめてから「完了回数と好みを記録する表も作って」と続けて頼めます。Ask for timestamps and page numbers so you can check the draft against its sources. Once you’ve reviewed this plan, you can follow up with “Make a sheet for recording task completions and display preferences.”

最初の設定はkAIgiで。Connect your agent in kAIgi.

  1. kAIgiの設定で「AI連携」を開きます。「Codex / Claude Code連携」で「CLIをインストール」を選び、Skillsをダウンロードします。Open AI Integration in kAIgi Settings. Under Codex / Claude Code Integration, choose Install CLI, then download the skills.
  2. 同じMacでCodexかClaude Codeを開き、「kAIgiを使って」に続けて依頼を書きます。Open Codex or Claude Code on the same Mac and start your request with “Use kAIgi to…”.

スキルを指定するには、CodexのCLIやIDE拡張では $kaigi、Claude Codeでは /kaigi で依頼を書き始めます。To select the skill explicitly, begin with $kaigi in the Codex CLI or IDE extension, or /kaigi in Claude Code.

CLIとSkillsの設定を詳しく見るOpen the CLI and skills setup guide

エージェントに渡す資料を選ぶ。Choose what your agent can read through kAIgi.

kAIgiは資料をMac上で読み取ります。CodexやClaude Codeでクラウドモデルを使う場合、取り出した発言や論文の本文が、そのモデルの提供元に送られることがあります。kAIgi retrieves source material on your Mac. If Codex or Claude Code uses a cloud model, the excerpts it retrieves may be sent to that model’s provider.

AI連携の設定にある「CLIに公開しないファイル・フォルダ」で、kAIgiのCLIから読み出せる資料を制限できます。In AI Integration settings, use Files and folders excluded from CLI to limit the documents your agent can retrieve through kAIgi’s CLI.
