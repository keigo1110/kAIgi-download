同じ資料を、三つの距離から。 Three ways to approach the same source library.

RECALL

結果を直接、速く読む Scan direct results quickly

保存済みの文字起こしと抽出済みPDFを横断し、一致箇所を一覧で比較します。候補を自分で読みたい時の最短経路です。 Search saved transcripts and extracted PDFs together, then compare matching passages directly. This is the shortest path when you want to inspect candidates yourself.

ASK

会話しながら絞り込む Narrow the library through conversation

「論文だけ」「一つ目を要約して」と続けて尋ね、候補探しから内容確認まで進めます。回答の出典から元の箇所を開けます。 Continue with prompts such as “papers only” or “summarize the first one,” moving from discovery to content questions while keeping source links.

ZOOM

全体を意味の地図で眺める See the whole library as a meaning map

カテゴリ、キーワード、資料へ連続的に近づき、会議と文献の近さを見渡します。検索しても地図を消さず、目的地だけを示します。 Move continuously from categories to keywords to sources and survey how meetings and papers relate. Search marks a destination without erasing the map.

実験的 Experimental

探して、続けて尋ねる。 Find a source, then keep asking.

01

曖昧な記憶から資料へ From a vague memory to exact sources

Askは自然な言葉から保存済み会議録と論文を横断します。候補名は生成せず、kAIgiにある正確なタイトルと根拠を返します。 Ask searches saved meetings and papers from natural language. It does not invent candidate titles; it returns exact library titles with evidence.

02

選んだ1資料を深く聞く Question one selected source closely

TextとAudioの「質問」は、今開いている論文または会議録だけを対象にします。要約や実験参加者数の回答から、元の段落・発話へ戻れます。 Questions in Text and Audio stay within the currently open paper or meeting. Answers such as summaries or participant counts link back to the source passage or utterance.

03

答えられない時も、作らない When evidence is weak, do not make an answer up

回答はこのMac内で処理し、会話は保存しません。対応モデルがない、根拠が足りない、生成に失敗した場合は、裏付けのない回答ではなく根拠候補を示します。 Answers are processed on this Mac and conversations are not saved. If no supported model is available, evidence is insufficient, or generation fails, kAIgi shows evidence candidates instead of an unsupported answer.

Install Install

Macに入れて、すぐ会議で使う。 Install on your Mac and use it in the next meeting.

  1. 1

    最新版DMGをダウンロード Download the latest DMG

    macOS 14以降を搭載したApple SiliconまたはIntel Macで、インストールボタンから kAIgi.dmg をダウンロードします。 On an Apple silicon or Intel Mac running macOS 14 or later, use the install button to download kAIgi.dmg.

  2. 2

    kAIgiを開く Open kAIgi

    kAIgi.dmg を開き、Finderに表示された kAIgi.app を起動します。 Open kAIgi.dmg, then launch kAIgi.app from the Finder window.

  3. 3

    Applicationsへ移動して開く Move to Applications

    確認画面で「移動して開く」を選ぶと、コピー先のアプリが自動で開き直されます。 Choose “Move and Open” when prompted. kAIgi copies itself to Applications and reopens from there.

  4. 4

    初回設定を済ませる Finish first-run setup

    会議音声を扱うためのmacOS確認とLocal LLMの準備を済ませます。Web検索を使う場合だけOpenAI API keyも設定します。 Complete the macOS prompts for meeting audio and prepare the Local LLM. Add an OpenAI API key only if you want to use web research.

Q&A Q&A

Micの許可がうまくいかない Microphone access is not working

kAIgiを終了し、Applications内の kAIgi.app から起動し直してください。一度拒否している場合は、システム設定のマイクでkAIgiをオンにします。 Quit kAIgi and reopen kAIgi.app from Applications. If access was denied once, enable kAIgi in macOS Microphone settings.

内部音声が入らない System audio is missing

システム設定の画面収録または画面とシステムオーディオ収録でkAIgiがオンになっているか確認し、変更後にアプリを再起動します。 Enable kAIgi in Screen Recording or Screen & System Audio Recording settings, then restart the app after changing the permission.

AI Researchが動かない AI Research is not producing cards

設定でAI Researchを有効にし、Local LLMの準備が完了しているか確認してください。Web検索を使うカードにはOpenAI API keyも必要です。議論内容が少ない時は、カードが出るまで少し発話が必要です。 Enable AI Research and confirm that the Local LLM is ready. Cards that use web research also require an OpenAI API key. If the discussion is still short, kAIgi may wait for more context before creating cards.

Askが文章で回答しない Ask shows evidence but no generated answer

Appleのオンデバイス回答にはmacOS 26以降とApple Intelligence対応環境が必要です。利用できない場合は、設定でLocal LLMの準備状況を確認してください。どちらも使えない時や根拠が不足する時は、推測せず確認できる根拠候補だけを表示します。 Apple's on-device answers require macOS 26 or later and an Apple Intelligence-capable environment. Otherwise, check that the Local LLM is ready in Settings. When neither model is available or evidence is insufficient, kAIgi avoids guessing and shows inspectable evidence candidates.

相手の声が二重に入る The other speaker is captured twice

スピーカー再生音がマイクにも入っている可能性があります。会議ではヘッドホンまたはイヤホンの使用を推奨します。 Your microphone may be picking up speaker output. Use headphones or earbuds during meetings.
