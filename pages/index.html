kAIgi 0.4.4 / Research context

読んだ文献を、次の論文の文脈へ。 Bring every paper you read into the next one.

01

手元の文献をまとめて探す Search the papers already on your Mac

kAIgiで本文を取り出した文献をCLIから横断し、テーマに近い論文と根拠段落をひとつの有界なコンテキストへまとめます。出版社サイトへ再アクセスする必要はありません。 Search papers whose text kAIgi has already extracted and collect relevant documents and evidence passages in one bounded context—without reopening publisher sites.

02

根拠の場所と版を失わない Keep every passage tied to its source

DOI・arXiv ID、PDFの版、ページ、段落ID、本文ハッシュを保ったまま渡します。自分のコメントは著者の主張と分けるため、関連研究の根拠へ戻れます。 Carry DOI or arXiv identity, PDF revision, page, block ID, and source hash with each passage. Your notes remain separate from author claims, so related-work drafts stay traceable.

03

読む流れを切らない Stay in the reading flow

PDFの切り替え、検索、サイドバー操作の表示を安定させ、不要なちらつきとレイアウト移動を抑えました。Reduce Motion設定にも一貫して従います。 PDF switching, search, and sidebar controls now keep stable geometry with less flicker and layout movement, while consistently respecting Reduce Motion.

Install Install

Macに入れて、すぐ会議で使う。 Install on your Mac and use it in the next meeting.

  1. 1

    最新版DMGをダウンロード Download the latest DMG

    macOS 14以降を搭載したApple SiliconまたはIntel Macで、インストールボタンから kAIgi.dmg をダウンロードします。 On an Apple silicon or Intel Mac running macOS 14 or later, use the install button to download kAIgi.dmg.

  2. 2

    kAIgiを開く Open kAIgi

    kAIgi.dmg を開き、Finderに表示された kAIgi.app を起動します。 Open kAIgi.dmg, then launch kAIgi.app from the Finder window.

  3. 3

    Applicationsへ移動して開く Move to Applications

    確認画面で「移動して開く」を選ぶと、コピー先のアプリが自動で開き直されます。 Choose “Move and Open” when prompted. kAIgi copies itself to Applications and reopens from there.

  4. 4

    初回設定を済ませる Finish first-run setup

    会議音声を扱うためのmacOS確認とLocal LLMの準備を済ませます。Web検索を使う場合だけOpenAI API keyも設定します。 Complete the macOS prompts for meeting audio and prepare the Local LLM. Add an OpenAI API key only if you want to use web research.

Q&A Q&A

Micの許可がうまくいかない Microphone access is not working

kAIgiを終了し、Applications内の kAIgi.app から起動し直してください。一度拒否している場合は、システム設定のマイクでkAIgiをオンにします。 Quit kAIgi and reopen kAIgi.app from Applications. If access was denied once, enable kAIgi in macOS Microphone settings.

内部音声が入らない System audio is missing

システム設定の画面収録または画面とシステムオーディオ収録でkAIgiがオンになっているか確認し、変更後にアプリを再起動します。 Enable kAIgi in Screen Recording or Screen & System Audio Recording settings, then restart the app after changing the permission.

AI Researchが動かない AI Research is not producing cards

設定でAI Researchを有効にし、Local LLMの準備が完了しているか確認してください。Web検索を使うカードにはOpenAI API keyも必要です。議論内容が少ない時は、カードが出るまで少し発話が必要です。 Enable AI Research and confirm that the Local LLM is ready. Cards that use web research also require an OpenAI API key. If the discussion is still short, kAIgi may wait for more context before creating cards.

相手の声が二重に入る The other speaker is captured twice

スピーカー再生音がマイクにも入っている可能性があります。会議ではヘッドホンまたはイヤホンの使用を推奨します。 Your microphone may be picking up speaker output. Use headphones or earbuds during meetings.
