同じ資料を、三つの距離から。 Three ways to approach the same source library.

RECALL

結果を直接、速く読む Scan direct results quickly

保存済みの文字起こしと抽出済みPDFを横断し、一致箇所を一覧で比較します。候補を自分で読みたい時の最短経路です。 Search saved transcripts and extracted PDFs together, then compare matching passages directly. This is the shortest path when you want to inspect candidates yourself.

ASK

会話しながら絞り込む Narrow the library through conversation

「論文だけ」「一つ目を要約して」と続けて尋ね、候補探しから内容確認まで進めます。回答の出典から元の箇所を開けます。 Continue with prompts such as “papers only” or “summarize the first one,” moving from discovery to content questions while keeping source links.

ZOOM

全体を意味の地図で眺める See the whole library as a meaning map

カテゴリ、キーワード、資料へ連続的に近づき、会議と文献の近さを見渡します。検索しても地図を消さず、目的地だけを示します。 Move continuously from categories to keywords to sources and survey how meetings and papers relate. Search marks a destination without erasing the map.

01

録音を優先してGemmaを使う Keep recording ahead of Gemma

録音、メモリ負荷、発熱、低電力モードを1つの資源ガバナが確認し、重い任意処理を開始前に延期します。ハーネスv3は根拠と主張を照合し、未検証の断定を公開しません。 One resource governor considers recording, memory pressure, thermal state, and Low Power Mode before optional heavy work starts. Harness v3 checks claims against evidence and withholds unsupported assertions.

02

PDFをページ単位で診断・補修する Diagnose and repair PDFs page by page

text layerをページごとに評価し、不足ページと理由を表示します。OCRは明示操作で推奨ページだけをApple Visionにより端末内処理し、正常な本文は置き換えません。 kAIgi evaluates each page's text layer and shows which pages need repair and why. An explicit action runs on-device Apple Vision only for recommended pages without replacing healthy text.

03

検索語と根拠の受け渡しを監査する Audit research queries and evidence handoff

Deep Researchは最大3つの検索語を期間・ドメインとともに送信前に表示します。CLIは同じ根拠をID・完全性・SHA-256付きパッケージへまとめ、選んだ外部モデルへ自分で渡せます。 Deep Research shows up to three queries with time and domain scope before sending. The CLI packages the same evidence with IDs, completeness, and SHA-256 for a user-controlled handoff to a selected external model.

Install Install

Macに入れて、すぐ会議で使う。 Install on your Mac and use it in the next meeting.

  1. 1

    最新版DMGをダウンロード Download the latest DMG

    macOS 14以降を搭載したApple Silicon Macで、インストールボタンから kAIgi.dmg をダウンロードします。 On an Apple Silicon Mac running macOS 14 or later, use the install button to download kAIgi.dmg.

  2. 2

    kAIgiを開く Open kAIgi

    kAIgi.dmg を開き、Finderに表示された kAIgi.app を起動します。 Open kAIgi.dmg, then launch kAIgi.app from the Finder window.

  3. 3

    Applicationsへ移動して開く Move to Applications

    確認画面で「移動して開く」を選ぶと、コピー先のアプリが自動で開き直されます。 Choose “Move and Open” when prompted. kAIgi copies itself to Applications and reopens from there.

  4. 4

    初回設定を済ませる Finish first-run setup

    会議音声を扱うためのmacOS確認を済ませます。AI Researchは設定で有効にするだけで使え、APIキーやLocal LLMの準備は不要です。 Complete the macOS prompts for meeting audio. AI Research works after you enable it in Settings, with no API key or Local LLM setup required.

Q&A Q&A

Micの許可がうまくいかない Microphone access is not working

kAIgiを終了し、Applications内の kAIgi.app から起動し直してください。一度拒否している場合は、システム設定のマイクでkAIgiをオンにします。 Quit kAIgi and reopen kAIgi.app from Applications. If access was denied once, enable kAIgi in macOS Microphone settings.

内部音声が入らない System audio is missing

システム設定の画面収録または画面とシステムオーディオ収録でkAIgiがオンになっているか確認し、変更後にアプリを再起動します。 Enable kAIgi in Screen Recording or Screen & System Audio Recording settings, then restart the app after changing the permission.

AI Researchが動かない AI Research is not producing cards

設定でAI Researchを有効にし、インターネット接続を確認してください。APIキーやLocal LLMは不要です。議論内容が少ない時は、検索する論点が見つかるまで少し発話が必要です。 Enable AI Research in Settings and check your internet connection. No API key or Local LLM is required. If the discussion is still short, kAIgi may wait until it finds a useful research question.

Askが文章で回答しない Ask shows evidence but no generated answer

回答はこのMac内で処理し、会話は保存しません。設定で検証済みGemma QAT Local LLMを準備するとAskと資料内質問で優先して使います。未準備なら、macOS 26以降の対応環境ではAppleのオンデバイスモデルへ戻ります。どちらも使えない時や根拠が不足する時は、推測せず確認できる根拠候補だけを表示します。 Answers are processed on this Mac and conversations are not saved. Prepare the verified Gemma QAT Local LLM in Settings to make it the preferred model for Ask and source Questions. When it is unavailable, supported macOS 26 systems fall back to Apple's on-device model. If neither can answer or evidence is insufficient, kAIgi avoids guessing and shows inspectable evidence candidates.

相手の声が二重に入る The other speaker is captured twice

スピーカー再生音がマイクにも入っている可能性があります。会議ではヘッドホンまたはイヤホンの使用を推奨します。 Your microphone may be picking up speaker output. Use headphones or earbuds during meetings.
